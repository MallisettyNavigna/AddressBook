# Address Book

A simple command-line address book written in C. It lets you store and manage contact details from the terminal.

## Features

- Add a new contact (name, phone number, email)
- Search for a contact
- Edit or delete an existing contact
- List all saved contacts

## Requirements

- A C compiler such as GCC

## How to Compile and Run

```bash
gcc addressbook.c -o addressbook
./addressbook
```

On Windows, run `addressbook.exe` instead of `./addressbook`.

## Usage

When the program starts, a menu appears. Type the number of the option you want and press Enter, then follow the prompts.
